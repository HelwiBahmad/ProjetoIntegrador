SLIDE 6: ARQUITETURA
================================================================================

ESTRUTURA MVC:

    FRONTEND (public/)
         ↓
    ← REQUISIÇÕES HTTP →
         ↓
    BACKEND (servidor/)
    • Controllers  → Requisições HTTP
    • Services    → Lógica de negócio
    • Repositories → Acesso a dados
         ↓
    BANCO DE DADOS (SQLite3)
    • Noticias, Categorias, Direitos
    • Eventos, Histórias, Usuários

BENEFÍCIOS:
  • Separação de responsabilidades
  • Fácil manutenção
  • Escalável
  • Testável

SLIDE 9: COMO USAR
================================================================================

INSTALAÇÃO:
  1. npm install
  2. npm run init-db (inicializar banco)
  3. npm start (iniciar servidor)
  4. Acessar: http://localhost:3000

USUÁRIOS DE TESTE:
  • Login com JWT
  • 3 perfis diferentes
  • Banco pré-populado

PAINEL ADMIN:
  • http://localhost:3000/admin.html
  • Gerenciar todo conteúdo
  • Dashboard com estatísticas
